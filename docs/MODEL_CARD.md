## ۲. کاربرد موردنظر

پارسیا برای **پژوهش، آموزش و نمایش شفاف ساخت مدل زبانی فارسی** ساخته شده است:

- ادامهٔ متن فارسی با سبک خبری، ادبی یا گفتگویی
- تولید بیت‌های کوتاه به سبک کلاسیک
- پاسخ به پرسش‌های ساده و قالب‌های گفتگویی که در داده دیده است
- نمایش زندهٔ آموزش، ارزیابی و استنتاج در رابط وب
- آزمون ایده‌های معماری و بهینه‌سازی روی سخت‌افزار محدود

## ۳. کاربردهای نامناسب

- تصمیم‌گیری پزشکی، حقوقی، مالی یا ایمنی‌محور
- ارائهٔ اطلاعات زمان‌دار (خبر، قیمت، هوا، تاریخ)
- ترجمهٔ حرفه‌ای یا پاسخ‌دهی به پرسش‌های واقعی که نیاز به دانش دقیق دارند
- جایگزینی مدل‌های بزرگ در محصولات واقعی
- هرگونه استفاده برای فریب، جعل هویت یا تولید انبوه محتوای گمراه‌کننده

مدل در این موارد **قابل اعتماد نیست** و ممکن است با اطمینانِ کاذب پاسخ نادرست بسازد.

## ۴. دادهٔ آموزش

پیکرهٔ نهایی حدود ۲۹ مگابایت (۱۶٫۷ میلیون نویسه) متن فارسی است:

| منبع | سهم تقریبی | توضیح |
|---|---|---|
| خبر و گزارش | ~۷۹٪ نویسه | Persian News Dataset (خبرگزاری‌های ایرانی) + Hamshahri Corpus |
| شعر کلاسیک | ~۲۰٪ نویسه | خاقانی، مولانا، سعدی، حافظ، خیام از گنجور |
| گفتگوی آغازین | ~۱٪ نویسه | ۸۰ نمونهٔ دست‌نویس پروژه، تکرارشده برای تثبیت قالب |

### پیش‌پردازش

1. یکسان‌سازی حروف عربی (`ي→ی`، `ك→ک`، `ة→ه`) و ارقام فارسی/عربی به لاتین
2. حذف اعراب، تشدید، کشیده و نویسه‌های کنترلی جهت‌دهی
3. حذف نشانی‌ها، ایمیل‌ها، تگ‌های HTML و عبارات تبلیغاتی خبرگزاری‌ها
4. محدودکردن نویسه‌ها به حروف فارسی/لاتین، ارقام، فاصله، نیم‌فاصله و نشانه‌گذاری
5. فیلتر نسبت فارسی (حداقل ۷۲٪ حروف) و حداقل طول/تعداد واژه
6. حذف تکراری‌ها با هش، شکستن اسناد بلند در مرز جمله
7. جداسازی ۲٪ اسناد برای اعتبارسنجی

پیکرهٔ خام به‌دلیل شرایط منابع در مخزن بازنشر نمی‌شود؛ ساخت آن با `scripts/fetch_corpora.sh` و `data/build_corpus.py` بازتولیدپذیر است.

## ۵. توکنایزر

- الگوریتم: BPE با شمارش جفتی وزنی و آموزش روی ۹ مگابایت نمونه از پیکره
- ۹٬۸۶۶ عمل ادغام؛ واژگان نهایی ۱۰٬۰۰۰ (با چهار نشانهٔ `<|doc|>`، `<|verse|>`، `<|user|>`، `<|bot|>`)
- میانگین **۴٫۲۵ نویسه بر توکن** روی دادهٔ اعتبارسنجی
- سرعت کدگذاری: حدود **۱٬۰۸۰٬۰۰۰ نویسه بر ثانیه** روی همان CPU
- نیم‌فاصله حفظ می‌شود تا «می‌شود» و «نمی‌دانم» شکسته نشوند
- نشانه‌گذاری به واژهٔ پیش از خود می‌چسبد تا «سلام،» یک واحد باشد

## ۶. آموزش

| پارامتر | مقدار |
|---|---|
| هدف | پیش‌بینی توکن بعدی با cross-entropy |
| بهینه‌ساز | AdamW (β₁=0.9، β₂=0.95، weight decay=0.1) |
| نرخ یادگیری | ۱٫۲×۱۰⁻³ با گرم‌کردن ۱۵۰ گام و کسینوس تا ۱٫۰×۱۰⁻⁴ |
| برش گرادیان | نرم کل ≤ ۱٫۰ |
| batch | ۲۴ دنباله × ۲۵۶ توکن = ۶٬۱۴۴ توکن بر گام |
| گام‌ها | ۱٬۸۰۰ (≈ ۱۱ میلیون توکن، حدود ۲٫۸ دوره) |
| ارزیابی | هر ۱۰۰ گام روی ۳ batch اعتبارسنجی |
| سخت‌افزار | ۲ هستهٔ vCPU Intel Xeon @ 2.60GHz، بدون GPU |
| زمان تقریبی | ~۹۵ دقیقه |
| سرعت | ~۱٬۹۰۰ توکن بر ثانیه · ~۷۵ گیگافلاپس مؤثر |

### آزمون صحت

- گرادیان تحلیلی در برابر گرادیان عددی: حداکثر خطای نسبی **۸٫۹۶×۱۰⁻⁷**
- تطابق حافظهٔ KV با پیش‌روی کامل: اختلاف حداکثر **~۳×۱۰⁻⁸**

| سنجه | مقدار |

## ۸. محدودیت‌ها

- **ظرفیت:** ۶٫۵۷ میلیون پارامتر برای یادگیری دانش عمومی و استدلال کافی نیست.
- **داده:** خبر + شعر + نمونهٔ کوچک گفتگو؛ نه پیکرهٔ دستوری، نه ویکی‌پدیای کامل.
- **زمان:** آموزش کوتاه و روی CPU؛ مدل به احتمال زیاد زیرآموزش (undertrained) است.
- **تکرار:** نمونه‌گیری می‌تواند به حلقه‌های تکراری بیفتد؛ جریمهٔ تکرار فقط آن را کم می‌کند.
- **واقعیت‌نمایی:** مدل «حقیقت» را نمی‌داند؛ الگوی زبانی را بازتولید می‌کند.
- **سوگیری:** پیکرهٔ خبری و ادبی سوگیری‌های خود را دارد (جنسیت، قومیت، سیاست، دین)؛ مدل آن‌ها را بازتاب می‌دهد.
- **ایمنی:** هیچ لایهٔ ردّ محتوا یا آموزش ایمنی وجود ندارد. برای استقرار عمومی باید فیلتر و محدودیت نرخ اضافه شود.

## ۹. اثر زیست‌محیطی

آموزش روی ۲ هستهٔ CPU و در حدود ۱٫۶ ساعت ≈ **۳٫۲ ساعت-core**. برآورد مصرف برق با توان ~۳۵ وات: حدود **۰٫۱ کیلووات‌ساعت**، معادل چند دقیقه روشنایی یک لامپ. این عدد در برابر آموزش مدل‌های بزرگ (مگاوات‌ساعت) ناچیز است، اما همان دلیل کوچکی مدل هم هست.

## ۱۰. بازتولید

```bash
bash scripts/fetch_corpora.sh
python data/build_corpus.py --sources ../corpora --out data
python data/train_tokenizer.py --vocab-size 10000
python -m parsia.train --steps 1800 --batch-size 24 --block-size 256 \
  --layers 5 --heads 4 --embed 256 --lr 1.2e-3 --seed 1337
python scripts/evaluate.py --checkpoint checkpoints/parsia-1-small.npz
```
