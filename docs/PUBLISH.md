# انتشار سایت رایان

دو چیز جدا باید منتشر شود:

1. **صفحه‌های استاتیک** (خانه، مدل‌ها، تعرفه، دوره، مستندات، دانلود)
2. **سرور پایتون** (چت، ورود، سهمیه، جست‌وجوی وب، پنل مدیر)

صفحه‌های استاتیک به‌تنهایی «سایت» نیستند؛ دکمهٔ «شروع گفتگو» به `/api/chat` روی همان دامنه
نیاز دارد. پس اگر فقط Pages را روشن کنی، یک نمایشگاهِ خواندنی می‌گیری، نه یک دستیار کارکن.

## ۱) صفحه‌های استاتیک روی GitHub Pages

گردش‌کار آماده است: `.github/workflows/pages.yml`

**یک قدم دستی لازم است** (API گیت‌هاب برای ساخت Pages از توکن این محیط ۴۰۳ می‌دهد):

> Settings → Pages → **Source: GitHub Actions**

بعد از آن، هر push روی `main` یا شاخهٔ این کار، سایت را می‌سازد و منتشر می‌کند:

```
https://<username>.github.io/ai/
```

نشانی بالا فقط صفحه‌های استاتیک را دارد. برای چت، مرحلهٔ ۲ لازم است.

## ۲) سرور (چت واقعی)

هر میزبان رایگانی که پایتون اجرا کند کافی است. مثال Render:

1. مخزن را به Render وصل کن.
2. `render.yaml` در مخزن هست؛ Blueprint را بپذیر.
3. متغیرها را ست کن:

| متغیر | معنی |
| --- | --- |
| `RAYAN_OWNER_PASSWORD` | گذرواژهٔ مالک (رمز پیش‌فرض را عوض کن) |
| `RAYAN_ENV=prod` | حالت تولید؛ بدون این، گذرواژهٔ پیش‌فرض ساخته می‌شود |
| `RAYAN_PUBLIC_URL` | نشانی کامل سرور برای sitemap |

بعد از بالا آمدن، دامنه را داخل کلاینت‌ها بگذار:

* در APK/EXE همان لحظهٔ نصب، کادر «نشانی سرور» را پر کن، یا
* متغیر مخزن `RAYAN_SERVER_URL` را ست کن و گردش‌کار `clients` را اجرا کن تا فایل‌های
  نصب با نشانی ثابت ساخته شوند.

## سریع‌ترین راه به یک سایت زنده

[Deploy to Render](https://render.com/deploy?repo=https://github.com/Taymaz1391/ai) را بزن،
`RAYAN_OWNER_PASSWORD` را وارد کن و بعد از دو دقیقه دامنهٔ `*.onrender.com` را داری؛
همان دامنه را در APK/EXE بگذار. سایت کامل (چت، ورود، پنل، جست‌وجو) همان‌جا کار می‌کند.

## چرا از این محیط نشد؟

* `POST /repos/.../pages` با توکن این محیط → **403 Resource not accessible by integration**
* همین خطا در گردش‌کار با `GITHUB_TOKEN` هم تکرار شد (`actions/configure-pages`)
  چون ساخت Pages مجوز مدیر مخزن می‌خواهد، نه مجوز گردش‌کار.
* دامنه‌های دیگر (Render/Fly/…) از این سندباکس در دسترس نیستند و نمی‌توان حساب ساخت.
* پیش‌نمایش موقت این محیط (`*.e2b.app`) درخواستِ بیرونی را با
  `403 Missing traffic access token` رد می‌کند و برای کاربر عمومی قابل استفاده نیست.

پس تنها کاری که این محیط **نمی‌تواند** انجام دهد، یک کلیکِ مالک مخزن است؛ بقیهٔ مسیر
(ساخت، آزمون، خروجی استاتیک، گردش‌کار، فایل‌های نصب) آماده است.
