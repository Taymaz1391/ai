# طرح ظرفیت ۱۰۰ میلیارد پارامتری

**وضعیت: فقط طرح معماری؛ آموزش و استقرار انجام نشده است.** مدل فعال سایت تغییر نکرده است.

این طرح با شکل پارامترهای پیاده‌سازی فعلی سازگار است: ۸۰ لایه، عرض ۱۰۲۴۰، ۸۰ سر توجه، واژگان ۶۴۰۰۰ و زمینهٔ ۴۰۹۶. تعداد دقیق: **۱۰۱٬۳۷۱٬۲۶۹٬۱۲۰ پارامتر**. افزایش تعداد پارامتر به‌تنهایی افزایش هوش نیست.

محاسبه بدون ساخت آرایه یا بارگذاری وزن‌ها:

```sh
python scripts/plan_100b.py
python -m unittest tests.test_plan_100b
```

## نیازهای تخمینی، نه منابع موجود

- وزن‌های BF16: حدود ۲۰۳ گیگابایت؛ وزن‌های FP32: حدود ۴۰۵ گیگابایت (ده‌دهی).
- وضعیت آموزش mixed-precision Adam: حداقل حدود ۱٫۶۲ ترابایت، **بدون** فعال‌سازی‌ها، بافرها و ارتباطات.
- بودجهٔ فرضی ۲۰ توکن به‌ازای هر پارامتر: حدود ۲٫۰۳ تریلیون توکن؛ دادهٔ موجود به این اندازه نیست.
- تخمین محاسبات با تقریب 6ND: حدود ۱٫۲۳ × ۱۰ به توان ۲۴ FLOP؛ زمان اجرا اندازه‌گیری نشده است.

آموزش‌دهندهٔ فعلی NumPy/CPU برای این مقیاس مناسب نیست؛ این فایل پشتیبانی آموزش توزیع‌شده یا BF16 اضافه نمی‌کند. پیش از آموزش واقعی، موتور توزیع‌شده، تقسیم وزن و وضعیت بهینه‌ساز، ذخیره و بازیابی چندبخشی، دادهٔ دارای مجوز و ارزیابی مستقل لازم است. هیچ وزن آماده، سرویس هوش مصنوعی بیرونی یا بنچمارک ساختگی در این طرح استفاده نشده است. تنظیمات سایت عمداً به این طرح متصل نیست تا با تخصیص صدها گیگابایت حافظه از کار نیفتد.
