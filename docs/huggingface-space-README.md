# پارسیا — هوش زبانی فارسی از صفر

مدل زبانی فارسی ۶٫۵۷ میلیون پارامتری که بدون API، بدون وزن آماده و بدون PyTorch ساخته شده است.
توکنایزر، ترنسفورمر، پس‌انتشار دستی، استنتاج و رابط کاربری همه در مخزن اصلی هستند.

این Space فقط میزبان سایت و مدل است. برای بازتولید آموزش به مخزن اصلی مراجعه کنید.

- گفتگو، ادامهٔ متن و شعر
- «اندیشهٔ ژرف»: چند مسیر موازی و انتخاب بهترین
- نمودار زندهٔ آموزش و شفافیت کامل اعداد

> این مدل کوچک است و ممکن است اشتباه کند؛ آن را جایگزین مدل‌های بزرگ ندانید.
