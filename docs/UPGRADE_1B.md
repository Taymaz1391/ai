# نقشهٔ مدل ۱ میلیارد پارامتری

این سند پاسخِ روشن به یک خواستهٔ مشخص است: **مدل ۱ میلیارد پارامتری، با حدود ۵ ساعت آموزش**.
عددها با `scripts/plan_1b.py` از روی `configs/rayan-1b.json` محاسبه می‌شوند؛ هیچ‌کدام دستی نوشته نشده‌اند.

## وضعیت امروز

| مورد | مقدار |
|---|---|
| مدلِ سرویس‌دهنده | ۱۶٫۹ میلیون پارامتر، NumPy، روی CPU |
| لایهٔ کیفیت پاسخ | بازیابی از پیکره + دستیار موضوعی + راهنمای گام‌به‌گام |
| آموزش ۱ میلیارد پارامتری | **انجام نشده** — به GPU نیاز دارد |

صراحت مهم است: چیزی که الان کار می‌کند، پاسخ‌های دقیق و سریع از لایهٔ دانش و راهنماست،
نه یک مدل ۱ میلیارد پارامتری. تا زمانی که آموزش زیر انجام نشود، هیچ‌جا ادعای ۱ میلیارد
پارامتر نمی‌شود.

## مشخصاتِ محاسبه‌شده

```
پارامتر:                ۱,۰۷۲,۲۵۰,۸۸۰
توکن لازم (۲۰× پارامتر): ۲۱٫۴۴ میلیارد
دادهٔ لازم (تقریب):      ۸۵ گیگابایت متن فارسی
حافظهٔ آموزش (bf16):     ۲۱ گیگابایت
حافظهٔ استنتاج:          ۳٫۱ گیگابایت
```

معماری: ترنسفورمر رمزگشا، ۲۰ لایه، عرض ۲۰۴۸، ۱۶ سر، FFN چهاربرابر، RMSNorm،
SwiGLU، RoPE، بلوک ۲۰۴۸ توکن، واژگان ۳۲ هزار، وزن‌های ورودی/خروجی مشترک.

## زمان و هزینه

| سخت‌افزار | زمان | هزینهٔ تقریبی |
|---|---|---|
| ۸×H100 80GB | ۶ ساعت | ~۱۱۹ دلار |
| ۸×A100 80GB | ۱۳ ساعت | ~۱۳۲ دلار |
| ۱×A100 80GB | ۱۰۸ ساعت | ~۱۳۰ دلار |

یعنی خواستهٔ «۱ میلیارد پارامتر در ۵ تا ۱۰ ساعت» **روی ۸×H100 شدنی است** و روی یک
GPU یا روی CPU این سرور شدنی نیست. جدول را با `python scripts/plan_1b.py` بازتولید کن.

## گام‌های اجرا

1. **داده** — ۸۵ گیگابایت متن فارسی با مجوز: ویکی‌پدیای بازبینی‌شده، خبر، پرسش‌وپاسخ.
   داده‌ای که امروز روی سرور است (۵۸۱ مگابایت) برای این کار کافی نیست؛ بزرگ‌ترین
   گلوگاه همین است، نه سخت‌افزار.
2. **توکن‌ساز** — BPE با واژگان ۳۲٬۰۰۰ روی ۱۰۰ میلیون نویسه از همان پیکره.
3. **آموزش** — PyTorch + FSDP + bf16 روی ۸×H100؛ گرادیان‌انباشت برای batch مؤثر ۲ میلیون توکن.
4. **هم‌ترازی** — SFT روی دادهٔ دستورِ خود پروژه، سپس بهینه‌سازی با پاداش (همان مسیر
   InstructGPT: SFT → مدل پاداش → PPO با جریمهٔ KL).
5. **ارزیابی** — `scripts/arena_benchmark.py` روی همان ۵۸ کار + دسته‌های جدید؛ عدد
   پیش و پس در `reports/` نگه داشته می‌شود.
6. **جایگزینی** — بارگذاری checkpoint تازه بدون قطعی، با همان مسیر بازنشستگیِ نسخهٔ قبل.

## چه چیزی از این کار در همین مخزن آماده است

* `configs/rayan-1b.json` — مشخصات کاملِ معماری و آموزش.
* `scripts/plan_1b.py` — شمارش پارامتر، حافظه، زمان و هزینه؛ خروجی JSON برای پیگیری.
* لایهٔ داده و توکن‌ساز پروژه (`rayan/tokenizer.py`, `scripts/build_wiki.py`) که با
  همان‌ها پیکرهٔ بزرگ‌تر ساخته می‌شود.

## چه چیزی در این محیط انجام نمی‌شود و چرا

این ماشین GPU ندارد. آموزش ۱٫۰۷ میلیارد پارامتر روی CPUِ چند هسته‌ای، با احتسابِ
حافظه و پهنای‌باند، ماه‌ها طول می‌کشد و در ۵ یا ۱۰ ساعت به هیچ نتیجهٔ قابل استفاده‌ای
نمی‌رسد. به‌جای ادعای عدد، مسیر و هزینه آماده شده تا اجرا روی سخت‌افزار درست انجام شود.
