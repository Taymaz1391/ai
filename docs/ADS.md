# کمپین تبلیغاتی گوگل — بستهٔ آمادهٔ رایان

این فایل متن‌های آمادهٔ کمپین را دارد تا بتوانی بدون بازنویسی، در Google Ads بارگذاری کنی.
خرید واقعی تبلیغ (حساب، بودجه، دامنهٔ عمومی) از این محیط ممکن نیست؛ اما همهٔ دارایی‌های خلاقانه
— ویدیو، پوستر، تیتر، توضیح و کلمات کلیدی — در همین مخزن ساخته شده‌اند.

## توضیح‌ها (حداکثر ۹۰ نویسه)

- **فا:** مدل زبانی فارسی که از صفر آموزش دیده؛ گفتگو، ابزار، استودیو تصویر و پنل مدیریت.
- **فا:** دورهٔ ۵ ساعتهٔ رایگان: پیکره، توکنایزر، ترنسفورمر، آموزش، امنیت و استقرار.
- **فا:** هیچ API خارجی؛ فونت، تصویر، ویدیو و استنتاج همه از همین مخزن سرو می‌شوند.
- **EN:** A Persian-first model trained from zero with NumPy. Chat, tools, image studio, admin.
- **EN:** A free five-hour course: corpus, tokeniser, transformer, training, security, deploy.
- **EN:** No external AI APIs. Fonts, video and inference served by one Python process.

## اندازه‌گیری

- ردیابی تبدیل در این پروژه از مسیر سرور انجام می‌شود: `/api/status` شمار درخواست‌ها و
  `/api/admin/overview` روند بازدید، ثبت‌نام و گفتگو را نشان می‌دهد.
- اگر GA4 اضافه کردی، آن را به‌عنوان اسکریپت میزبانی‌شده اضافه نکن؛ CSP پروژه اسکریپت بیرونی
  را مسدود می‌کند. نسخهٔ سازگار: یک endpoint سبک در همین سرور که رخدادها را در SQLite ثبت کند.
- معیار موفقیت آزمایش دو هفته‌ای: هزینهٔ هر ثبت‌نام زیر ۲ دلار و نرخ ماندگاری روز هفتم بالای ۱۰٪.
