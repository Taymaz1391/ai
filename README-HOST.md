# رایان روی هاست — راهنمای آپلود

این بسته همه‌چیزِ لازم را دارد: کد، مدل، دانشنامه، صفحه‌ها و فایل‌های راه‌اندازی.
نه به سرویس هوش مصنوعی بیرونی وصل می‌شود، نه به پایگاه‌دادهٔ بیرونی.

> **یک نکتهٔ صادقانه:** «هاست» دو نوع است. اگر پنل هاستت **Python App / Passenger**
> دارد (بیشتر هاست‌های ایرانی cPanel این را دارند) همین بسته کافی است. اگر فقط
> PHP دارد و پایتون اجرا نمی‌کند، هیچ بسته‌ای به‌تنهایی کار نمی‌کند؛ آن‌وقت راهِ
> درست، VPS یا Docker است (پایین توضیح داده‌ام).

---

## ۱) پیش‌نیازهای هاست

| لازم | چرا |
|---|---|
| پایتون **۳.۱۰ یا بالاتر** | کد با نسخه‌های تازه نوشته شده |
| **Python App** (Passenger) یا mod_wsgi | برنامه FastAPI است و باید به‌صورت WSGI اجرا شود |
| دست‌کم **۵۰۰ مگابایت رم** | مدل ۲۴ مگابایتی است؛ کل فرایند حدود ۱۵۰–۲۵۰ مگابایت |
| حدود **۶۰ مگابایت** فضا | بسته + پوشهٔ داده |
| نوشتن در یک پوشه | پایگاه‌داده، کلید امنیتی و لاگ نوشته می‌شوند |

اگر در پنل، بخش **Setup Python App** را می‌بینی، همه‌چیز آماده است.

---

## ۲) آپلود (cPanel — رایج‌ترین)

1. وارد cPanel شو → **File Manager**.
2. پوشهٔ برنامه را بساز، مثلاً `rayan` در کنار `public_html`
   (اگر می‌خواهی سایت روی دامنهٔ اصلی باشد، همان `public_html` هم می‌شود).
3. فایل `rayan-host.zip` را **Upload** کن.
4. روی فایل کلیک راست → **Extract** → مطمئن شو `passenger_wsgi.py` در ریشهٔ همان
   پوشه است (نه داخل یک پوشهٔ تودرتو).
5. اگر پنل اجازه داد، دو پوشه بساز: `var` و `logs` (برنامه خودش هم می‌سازد).

---

## ۳) ساخت برنامهٔ پایتون (cPanel)

**Setup Python App** → **Create Application**:

| فیلد | مقدار |
|---|---|
| Python version | ۳.۱۰ یا ۳.۱۱ (بالاترین موجود) |
| Application root | همان پوشه‌ای که فایل‌ها را باز کردی (`rayan`) |
| Application URL | دامنه یا زیردامنه؛ مثلاً `rayan.example.com` |
| Application startup file | `passenger_wsgi.py` |

سپس در همان صفحه:

1. **Run Pip Install** را بزن و `requirements.txt` را بده (یا در بخش ترمینال:
   `pip install -r requirements.txt`).
2. **Environment variables** را باز کن و این‌ها را اضافه کن:

   | متغیر | مقدار | لازم؟ |
   |---|---|---|
   | `RAYAN_OWNER_PASSWORD` | یک گذرواژهٔ قوی برای پنل مدیریت | **بله** |
   | `RAYAN_PUBLIC_URL` | نشانی کامل سایت، مثل `https://rayan.example.com` | بله |
   | `RAYAN_ENV` | `production` | پیش‌فرض است |
   | `RAYAN_COOKIE_SECURE` | اگر سایت **HTTPS** نداشت `0` بگذار | فقط برای HTTP |
   | `RAYAN_BASE_PATH` | اگر برنامه روی زیرشاخه است، مثل `/rayan` | فقط زیرشاخه |
   | `RAYAN_DATA_DIR` | مسیر پوشهٔ نوشتنی، اگر پیش‌فرض کار نکرد | اختیاری |

3. **Restart** را بزن.

---

## ۴) آزمایش

۱. در مرورگر: `نشانی-سایت/api/health` → باید `{"ok": true, ...}` ببینی.
   (تا وقتی مدل بارگذاری شود ممکن است `ok` چند ثانیه `false` باشد.)
۲. `/admin` را باز کن و با `RAYAN_OWNER_PASSWORD` وارد شو.
۳. `/` را باز کن و یک پرسش بپرس.

اگر به ترمینال پنل دسترسی داری، یک فرمان همه‌چیز را بررسی می‌کند:

```bash
python deploy/host_check.py
```

خروجی یک فهرست ✓/✗ می‌دهد و برای هر ✗ راهِ حل کوتاه.

---

## ۵) دو نکته که بیشترِ خرابی‌ها از آن‌هاست

**بدون HTTPS، کوکی ورود نمی‌چسبد.** در `production` کوکی‌ها `Secure` هستند؛ اگر
سایت با `http://` باز می‌شود، در متغیرهای محیطی `RAYAN_COOKIE_SECURE=0` بگذار یا
(بهتر) SSL رایگان هاست را روشن کن.

**زیرشاخه.** اگر نشانی سایت `https://example.com/rayan` است، باید
`RAYAN_BASE_PATH=/rayan` را هم تعریف کنی؛ وگرنه فایل‌های CSS و درخواست‌های API به
ریشهٔ دامنه می‌روند و صفحه سفید می‌شود.

---

## ۶) اگر هاست فقط PHP دارد

این برنامه پایتون اجرا می‌کند؛ روی هاستِ فقط-PHP بالا نمی‌آید. دو راه:

* **VPS ارزان** (۱ هسته، ۱ گیگ رم کافی است): `compose.yaml` را با Docker بالا بیاور.
* **سرویس‌های آماده:** `Dockerfile` و `render.yaml` در بسته هست؛ روی Render یا
  Hugging Face Space (نوع Docker) در چند دقیقه بالا می‌آید.

---

## ۷) عیب‌یابی

| نشانه | علتِ رایج | راهِ حل |
|---|---|---|
| خطای ۵۰۰ در همان صفحهٔ اول | بستهٔ پایتون نصب نشده | «Run Pip Install» با `requirements.txt` |
| صفحهٔ سفید، بدون CSS | زیرشاخه بدون `RAYAN_BASE_PATH` | `RAYAN_BASE_PATH=/rayan` و Restart |
| ورود می‌کنی ولی مهمان می‌مانی | کوکی `Secure` روی HTTP | `RAYAN_COOKIE_SECURE=0` یا SSL |
| `database is locked` | دو نمونهٔ برنامه هم‌زمان | یک Application بساز؛ Restart کن |
| کندیِ اولین پاسخ | مدل تازه در حافظه بار شده | عادی است؛ پاسخ‌های بعدی زیر ۰٫۱ ثانیه |
| خطای نوشتن فایل | پوشهٔ برنامه خواندنی است | `RAYAN_DATA_DIR=~/rayan-data` |

---

## ۸) نگه‌داری و به‌روزرسانی

* **پشتیبان:** پوشهٔ `var/` (یا `RAYAN_DATA_DIR`) را دانلود کن؛ همهٔ حساب‌ها و
  گفتگوها همان‌جاست. پنل مدیریت هم در بخش نگه‌داری «پشتیبان» می‌سازد.
* **به‌روزرسانی:** فایل zip تازه را بساز، در همان پوشه Extract کن (فایل‌های `var/`
  دست‌نخورده می‌مانند) و Restart بزن.
* **حذف:** Application را در پنل حذف و پوشه را پاک کن؛ دادهٔ شخصی جای دیگری نیست.
