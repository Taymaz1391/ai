# پارسیا

**یک مدل زبانی فارسی، ساخته‌شده از صفر — بدون API، بدون وزن آماده، بدون PyTorch**

## پارسیا چیست؟

پارسیا یک پروژهٔ متن‌باز برای ساختن **مدل زبانی فارسی از پایه** است. همهٔ اجزای آن در همین مخزن نوشته شده‌اند: شکستن متن فارسی به توکن، معماری ترنسفورمر، مشتق‌گیری دستی، بهینه‌ساز، استنتاج با حافظهٔ KV، جست‌وجوی چندمسیره، سرور و رابط کاربری. مدل با متن فارسی واقعی (خبر، کتاب و شعر) آموزش دیده و گفتگو را کاملاً روی همان دستگاهی اجرا می‌کند که سرور روی آن است.

این پروژه **ادعای رقابت با مدل‌های بزرگ امروزی را ندارد**. مدلی با ۶٫۵ میلیون پارامتر، روی دو هستهٔ CPU و در حدود دو ساعت آموزش، از نظر توان زبانی در سطح مدل‌های میلیاردپارامتری نیست. اما چیزی را نشان می‌دهد که اغلب پشت APIها پنهان می‌ماند: **کل مسیر ساخت، خوانا، آزمون‌پذیر و قابل تکرار است.**

> اگر دنبال یک مدل آماده و قدرتمند هستید، این پروژه آن نیست. اگر دنبال فهمیدن و ساختنِ واقعی یک مدل زبانی فارسی هستید، جای درستی آمده‌اید.

---

## چه چیزی از صفر نوشته شده است؟

| بخش | توضیح |
|---|---|
| **توکنایزر** | BPE با آموزش روی پیکرهٔ فارسی؛ نیم‌فاصله (ZWNJ) جزئی از واژه می‌ماند و نشانه‌گذاری به واژهٔ قبل می‌چسبد. |
| **مدل** | ترنسفورمر رمزگشا: توجه چندسری، LayerNorm، SiLU، اتصال باقی‌مانده و وزن مشترک خروجی/امبدینگ. |
| **پس‌انتشار** | گرادیان‌ها با NumPy و به‌صورت دستی نوشته شده‌اند؛ با گرادیان عددی تا خطای نسبی `< 10⁻⁵` آزموده شده است. |
| **آموزش** | AdamW با زمان‌بندی کسینوسی و گرم‌کردن، برش گرادیان، ارزیابی دوره‌ای و ذخیرهٔ بهترین checkpoint. |
| **استنتاج** | حافظهٔ KV برای تولید توکن‌به‌توکن، نمونه‌گیری با دما، top-k، top-p و جریمهٔ تکرار. |
| **اندیشهٔ ژرف** | تولید چند مسیر موازی و انتخاب بهترین با امتیاز اطمینان، تکرار، فارسی‌بودن و پایان جمله. |
| **داده** | پاک‌سازی، یکسان‌سازی و سندبندی ۲۹ مگابایت متن فارسی از خبرگزاری‌ها و شعر کلاسیک. |
| **رابط** | HTML/CSS/JS خالص، RTL، فونت وزیرمتن، نمودارهای زندهٔ آموزش و گفتگوی جریانی. |

## شروع سریع

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python web/server.py --host 0.0.0.0 --port 8000
```

سپس <http://localhost:8000> را باز کنید. برای گفتگو در ترمینال:

```bash
python - <<'PY'
from parsia.generate import Engine
engine = Engine("checkpoints/parsia-1-small.npz", "tokenizer/parsia_bpe.json")
answer, gen, prompt = engine.reply("سلام! خودت را معرفی کن")
print(answer)
print(f"{gen.tokens_per_second:.0f} tok/s · confidence={gen.confidence:.2f}")
PY
```

> اولین اجرا ممکن است چند ثانیه برای بارگذاری مدل و گرم‌شدن NumPy زمان ببرد.

## از صفر تا مدل

```bash
# ۱) دانلود پیکره‌های عمومی فارسی (در پوشهٔ بیرونی)
bash scripts/fetch_corpora.sh

# ۲) ساخت پیکرهٔ تمیز ۲۹ مگابایتی
python data/build_corpus.py --sources ../corpora --out data

# ۳) آموزش توکنایزر BPE با ۱۰٬۰۰۰ توکن
python data/train_tokenizer.py --vocab-size 10000

# ۴) آموزش پایه (حدود ۱۰۳ دقیقه روی ۲ هستهٔ CPU)
python -m parsia.train --steps 1800 --batch-size 24 --block-size 256 \
    --layers 5 --heads 4 --embed 256 --lr 1.2e-3

# ۵) ادامهٔ آموزش روی پیکرهٔ گفتگویی بزرگ‌تر (حدود ۳۲ دقیقه)
python -m parsia.train --resume checkpoints/parsia-1-small.npz --steps 2400 \
    --batch-size 24 --block-size 256 --lr 3.5e-4 --min-lr 3e-5 --warmup 60

# ۶) ارزیابی، نمونه‌سازی و ساخت نمایش نمونه‌ها برای سایت
python scripts/evaluate.py --checkpoint checkpoints/parsia-1-small.npz
python scripts/build_showcase.py --evaluation reports/evaluation.json
```

اگر GPU دارید، کافی است همین ماتریس‌ها را با PyTorch بازنویسی کنید؛ داده، توکنایزر و قالب گفتگو آماده‌اند. هدف این مخزن، شفافیت و اجرا روی CPU است، نه بیشترین سرعت.

## معماری در یک نگاه

```
متن فارسی
   │  نرمال‌سازی: ي→ی، ك→ک، حذف اعراب، یکسان‌سازی ارقام و نشانه‌ها
   ▼
BPE فارسی (۱۰٬۰۰۰ توکن) ──► دنبالهٔ توکن‌ها
   ▼
امبدینگ واژه + امبدینگ موقعیت (۲۵۶ بُعد، زمینهٔ ۲۵۶)
   ▼
۵ × بلوک ترنسفورمر
   ├─ LayerNorm → توجه چندسری (۴ سر، ماسک علّی) → اتصال باقی‌مانده
   └─ LayerNorm → خطی ۲۵۶→۱۰۲۴ → SiLU → خطی ۱۰۲۴→۲۵۶ → اتصال باقی‌مانده
   ▼
LayerNorm پایانی ─► پیش‌بینی واژگان (وزن مشترک با امبدینگ)
   ▼
نمونه‌گیری: دما · top-k · top-p · جریمهٔ تکرار · توقف روی نشانه‌های گفتگو
```

جزئیات ریاضی و پیاده‌سازی در [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) آمده است.

### قالب پیکره و گفتگو

```text
<|doc|> <|user|> تو کی هستی؟ <|bot|> من پارسیا هستم؛ یک مدل زبانی کوچک فارسی… <|doc|> ای دل اگر به عشق…
```

قالب گفتگو از ۱۴۰ نمونهٔ دست‌نویس (تکرارشده در پیکره) می‌آید تا مدل کوچک بتواند نقش «دستیار» را از نقش «کاربر» جدا کند.

## API

| مسیر | کار |
|---|---|
| `GET /api/health` | وضعیت مدل و آموزش |
| `GET /api/model` | مشخصات، سخت‌افزار، پیکره و محدودیت‌ها |
| `GET /api/metrics` | گزارش زندهٔ آموزش (`logs/metrics.jsonl`) |
| `GET /api/samples` | پیشنهادهای شروع گفتگو |
| `POST /api/chat` | پاسخ کامل؛ با `deep: true` جست‌وجوی چندمسیره |
| `POST /api/chat/stream` | پاسخ جریانی به‌صورت NDJSON |
| `GET /api/showcase` | نمونه‌های واقعی تولید مدل |
| `GET /api/download/checkpoint` | دانلود وزن‌های مدل (NPZ) |
| `DELETE /api/session/{id}` | پاک‌کردن تاریخچهٔ نشست |

```bash
curl -s -X POST localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"یک شعر بگو","deep":true,"candidates":4}' | python -m json.tool
```

## نتایج واقعی

نتایج کامل و به‌روز در [`docs/MODEL_CARD.md`](docs/MODEL_CARD.md) منتشر می‌شود. خلاصه:

| سنجه | مقدار |
|---|---|
| پارامترهای آموزش‌پذیر | ۶٬۵۷۴٬۸۴۸ |
| توکن‌های آموزش | ۱۴٬۷۴۵٬۶۰۰ (دو فاز، ~۳٫۷ دوره از پیکره) |
| طول زمینه | ۲۵۶ توکن |
| سخت‌افزار | ۲ هستهٔ vCPU · بدون GPU |
| سرعت آموزش | ~۱٬۸۹۰ توکن بر ثانیه روی ۲ هستهٔ CPU |
| خطای اعتبارسنجی | ۵٫۳۱ nats/token |
| Perplexity | ۲۰۲٫۴ |
| بیت بر نویسه | ۱٫۸۱ |
| دقت top-1 / top-5 | ۱۷٫۴٪ / ۳۴٫۱٪ |

هیچ عددی در رابط کاربری ساختگی نیست؛ همه از `logs/metrics.jsonl` و متادیتای checkpoint خوانده می‌شوند.

## محدودیت‌ها (صادقانه)

- **اندازه:** ۶٫۵ میلیون پارامتر در برابر ده‌ها یا صدها میلیارد پارامتر مدل‌های امروزی.
- **دانش:** فقط آنچه در پیکره بوده؛ بدون اینترنت، خبر تازه یا جست‌وجو.
- **دقت:** ممکن است جمله‌های نادرست، تکراری یا بی‌ربط بسازد. پاسخ‌ها را بررسی کنید.
- **زبان:** پیکره ترکیبی خبر، شعر و گفتگوست؛ سبک خروجی بین این سه نوسان می‌کند.
- **آموزش:** روی CPU و در زمان محدود؛ نه با خوشهٔ GPU و نه با دادهٔ صدها میلیارد توکنی.
- **«اندیشهٔ ژرف»:** جست‌وجوی چندمسیره و امتیازدهی است، نه تفکر آگاهانه.
