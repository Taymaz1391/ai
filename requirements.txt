# Local Intelligence Engine

یک پروژهٔ حرفه‌ای و کاملاً محلی برای ساخت مدل زبانی از صفر، بدون اتصال به API یا سرویس خارجی.

این مخزن شامل سه لایهٔ اصلی است:

- مدل پایهٔ GPT از صفر
- آموزش روی دادهٔ متنی محلی
- چت تعاملی و سیستم حافظهٔ ساده برای کارهای واقعی‌تر

> این نسخه، یک پایهٔ قوی برای یادگیری و توسعهٔ یک مدل زبانی شخصی است. برای ساخت مدل عظیم حرفه‌ای مثل ChatGPT، نیاز به دادهٔ بسیار بزرگ، GPUهای قوی، ارزیابی پیوسته و tuning حرفه‌ای دارید. ولی این پروژه، مسیر واقعی و عملی برای ساخت مدل محلی و توسعه‌پذیر است.

## ویژگی‌ها

- tokenizer byte-level برای زبان‌های مختلف
- GPT decoder-only با masked self-attention
- residual blocks + layer norm
- checkpoint save/load
- generation با temperature/top-k/top-p
- chat mode
- memory-based agent mode
- قابل توسعه برای fine-tuning و دادهٔ فارسی/انگلیسی

## نصب

```bash
python -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

## آموزش مدل

یک فایل متنی UTF-8 بسازید، مثال `data.txt`.

```bash
python train.py --input data.txt --output checkpoints/local_model.pt --steps 4000 --batch-size 16 --block-size 256 --layers 8 --heads 8 --embed 512
```

## چت تعاملی

```bash
python chat.py --checkpoint checkpoints/local_model.pt
```

یا با یک پرامپت یک‌باره:

```bash
python chat.py --checkpoint checkpoints/local_model.pt --prompt "سلام، تو چه‌کمکی می‌تونی بکنی؟"
```

## اجرای agent با حافظه

```bash
python agent.py --checkpoint checkpoints/local_model.pt
```

در حالت agent، مدل می‌تواند پاسخ‌ها را به حافظهٔ محلی اضافه کند و در مکالمات بعدی از آن استفاده کند.

## مسیر توسعه به نسخهٔ حرفه‌ای‌تر

برای ارتقاء مدل:

- دادهٔ بزرگ‌تر و تمیزتر
- tokenizer بهتر (BPE/SentencePiece)
- instruction-tuning روی دادهٔ گفتگو
- preference optimization (DPO / RLHF)
- training روی GPUهای قوی‌تر
- evaluation و benchmark
- memory و tool-use
