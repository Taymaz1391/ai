هوش، فقط از سایت یا با کلید API

مدل روی همین سرور اجرا می‌شود و راه دیگری برای رسیدن به آن نیست: یا از خود سایت گفتگو می‌کنی، یا یک کلید API می‌سازی و از برنامهٔ خودت صدا می‌زنی. کلیدها با هش ذخیره می‌شوند و هر لحظه قابل لغو‌اند.

کلیدهای من

هر کلید فقط یک‌بار نمایش داده می‌شود؛ همان لحظه کپی کن.

برای ساخت کلید وارد حساب شو.

    فراخوانی

    یک درخواست ساده؛ پاسخ همان چیزی است که سایت می‌بیند.

    curl -X POST https://your-host/api/chat \
  -H "X-API-Key: rk_..." \
  -H "Content-Type: application/json" \
  -d '{"message": "یک بیت دربارهٔ باران بگو"}'
    • سقف بدنه: ۵۱۲ کیلوبایت · سقف پیام: ۲۰۰۰ نویسه
    • نرخ: ۴۵ درخواست در دقیقه برای هر IP
    • کلید نامعتبر یا لغوشده: خطای ۴۰۱
    • بدون کلید و بدون کوکی سایت: خطای ۴۰۱ — مدل جای دیگری باز نیست

    در متغیر محیطی سرور خودت، نه در کد سمت مرورگر. اگر کلید لو رفت، همان لحظه از همین صفحه لغوش کن.

    نه. درخواست به /api/chat بدون کوکی نشست/مهمان یا کلید معتبر با خطای ۴۰۱ رد می‌شود.

    حداکثر ۱۰ کلید فعال برای هر حساب؛ برای هر دستگاه یا سرویس یک کلید جدا بساز تا لغو کردنش ساده باشد.

    دستیار فارسی که از صفر ساخته شده؛ کد، داده و وزن‌ها عمومی‌اند.
