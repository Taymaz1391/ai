شفاف، حتی وقتی به نفع ما نیست

نه. از نظر مقیاس با مدل‌های میلیاردپارامتری فاصلهٔ زیادی دارد: ۶٫۵۷ میلیون پارامتر در برابر صدها میلیارد. هدف این پروژه ساختن یک جایگزین نیست؛ نمایش شفاف ساخت یک مدل زبانی فارسی از صفر است. اما تجربهٔ محصولش — حساب، تاریخچه، جریان پاسخ، اشتراک‌گذاری — کامل است.

خیر. وزن‌ها از صفر مقداردهی و آموزش داده شده‌اند؛ توکنایزر هم روی پیکرهٔ خودمان آموزش دیده. تنها وابستگی‌ها NumPy، FastAPI و SQLite هستند — نه وزن آماده، نه API بیرونی.

چون مدل کوچک و آموزش کوتاه است. مدل جمله‌های فارسیِ محلی و بافت‌دار می‌سازد، اما دانش عمومی، استدلال و انسجام طولانی‌مدت در آن ضعیف است. این محدودیت در کارت مدل مستند شده و در رابط کاربری هم اعلام می‌شود.

در یک پایگاه‌دادهٔ SQLite روی همان سروری که سایت را اجرا می‌کند. هیچ داده‌ای به سرویس‌های خارجی فرستاده نمی‌شود. رمز عبور با scrypt و نمک یکتا ذخیره می‌شود و نشست‌ها با کوکی HttpOnly مدیریت می‌شوند.

مخزن عمومی است: کافی است pip install -r requirements.txt و سپس python web/server.py. همه‌چیز روی CPU کار می‌کند. راهنمای استقرار رایگان (Hugging Face Spaces و Render) هم در مستندات آمده است.
