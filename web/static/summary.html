همه‌چیز، در یک نگاه

یک محصول کاملِ فارسی‌زبان است که از صفر ساخته شده: مدل زبانی با آموزش مستقل، رابط گفتگو، ابزارها، استودیو تصویر، پنل مدیریت، تبلیغات و تعرفهٔ پویا. هیچ API بیرونی‌ای در آن استفاده نمی‌شود.

لینک زندهٔ همین نسخه همیشه در بالای صفحهٔ پیش‌نمایش همین محیط است.

هوش و مدل

  • ترنسفورمر دیکودر فقط با NumPy، بدون وزن آماده
  • توکنایزر BPE با واژگان ۱۰٬۰۰۰ فارسی
  • حالت‌های گفتگو، ادامهٔ متن و شعر
  • اندیشهٔ ژرف با چند کاندید و توضیح مسیر
  • نرمال‌سازی فارسی و پاک‌سازی خروجی

محصول

  • صفحهٔ خانه، گفتگو، مدل‌ها، تعرفه، مستندات
  • حساب کاربری، مهمان، اشتراک‌گذاری گفتگو
  • خروجی Markdown و استودیو تصویر (PNG/SVG)
  • ابزارهای تاریخ شمسی، ماشین‌حساب و تبدیل یکا
  • سایت تک‌زبانهٔ فارسی و راست‌چین؛ بدون کلید زبان و بدون هدایت خودکار
  • حرکت برند: کرهٔ زندهٔ دستیار و نشان متحرک شفاف، با نمایش تمام‌صفحهٔ پس از ثبت‌نام
  • دورهٔ ۵ ساعتهٔ کامل، بدون آکادمی و بدون ثبت‌نام
  • بستهٔ آمادهٔ تبلیغ گوگل (docs/ADS.md)

مدیریت و درآمد

  • پنل مدیریت با ورود جدا و CSRF
  • تبلیغات با جایگاه، وزن، نمایش و کلیک
  • تعرفهٔ پویا: قیمت، مدت و درگاه قابل تنظیم
  • پرچم‌های قابلیت، اعلان و حالت نگهداری
  • لاگ حسابرسی، بکاپ، VACUUM و خودآزمون

امنیت

  • CSP سخت‌گیرانه بدون اسکریپت درون‌خطی
  • کوکی HttpOnly، SameSite و CSRF ادمین
  • قفل ورود پس از تلاش‌های ناموفق
  • کنترل مبدأ درخواست‌های تغییردهنده
  • بدون منبع بیرونی؛ مقاوم در شبکهٔ محدود

آنچه واقعاً ممکن نیست

  • یک میلیارد کاربر همزمان روی یک پردازنده
  • آموزش مدل هزار‌میلیارد پارامتری روی CPU
  • آموزش روی «تمام گوگل» (غیرقانونی و ناممکن)
  • پاسخ انگلیسی: مدل فقط با متن فارسی آموزش دیده است
  • تصویر واقع‌گرا بدون مدل diffusion و GPU

مسیر بزرگ‌شدن

  • کپی‌های بی‌حالت پشت متعادل‌کنندهٔ بار
  • صف محدود و پاسخ ۵۰۳ هنگام اشباع
  • CDN برای دارایی‌های تغییرناپذیر
  • انتقال پایگاه‌داده به Postgres
  • استنتاج روی GPU با کوانتیزه‌سازی

اجرای محلی در سه خط

git clone https://github.com/Taymaz1391/ai.git
cd ai && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && python -m web.server --port 8000

رمز مدیریت در اولین اجرا ساخته و چاپ می‌شود؛ با متغیر RAYAN_ADMIN_PASSWORD هم قابل تعیین است.
