رایان چیست و چرا ساخته شد؟

هوش مصنوعی فارسی · نسخهٔ ۱٫۰ · ساخته‌شده از صفر با NumPy

چرا رایان؟

بیشتر دستیارهای هوش مصنوعی که فارسی حرف می‌زنند، مدل‌های بزرگی هستند که در جای دیگر ساخته شده‌اند و فارسی برایشان زبان دوم است. رایان یک آزمایش است در جهت مخالف: یک مدل کوچک که فقط با متن فارسی بزرگ شده و تمام مسیرش — از پاک‌سازی داده تا رابط کاربری — در همین پروژه و شفاف است.

هدف، رقابت با مدل‌های بزرگ نیست. هدف این است که نشان دهیم ساختن یک مدل زبانی فارسی از صفر روی یک لپ‌تاپ معمولی ممکن است، اگر انتظارات را صادقانه تعریف کنیم.

چطور ساخته شد

  1. پیکره: ۱۶٫۹ میلیون نویسه از خبر فارسی، روزنامهٔ همشهری و شعر کلاسیک گنجور، با پاک‌سازی و نرمال‌سازی.
  2. توکنایزر: BPE با ۱۰٬۰۰۰ توکن، آموزش‌دیده روی همین پیکره؛ حفظ نیم‌فاصله و چسبیدن نشانه‌گذاری.
  3. مدل: ترنسفورمر رمزگشا با ۵ لایه، ۴ سر، بُعد ۲۵۶ و زمینهٔ ۲۵۶ توکن — ۶٬۵۷۴٬۸۴۸ پارامتر.
  4. آموزش: پیش‌رو و پس‌رو دستی با NumPy و AdamW؛ ۲٬۴۰۰ گام و ۱۴٫۷ میلیون توکن در دو فاز.
  5. سرویس: FastAPI با حافظهٔ KV، جریان NDJSON، حساب کاربری SQLite و همین رابط فارسی.

آزمون صحت: گرادیان تحلیلی در برابر گرادیان عددی با حداکثر خطای نسبی ۸٫۹۶×۱۰⁻⁷ و تطابق حافظهٔ KV با پیش‌روی کامل با اختلاف ~۳×۱۰⁻⁸.

پشتهٔ فنی

  • Python 3.11 · NumPy (بدون PyTorch/JAX)
  • FastAPI + Uvicorn — API و سرو فایل‌های ایستا
  • SQLite (کتابخانهٔ استاندارد) — کاربر، گفتگو، پیام، اشتراک
  • CSS و JavaScript خالص — بدون React یا فریم‌ورک ظاهری
  • فونت Vazirmatn با مجوز OFL

منابع داده

مدل با احترام به تلاش گردآورندگان این پیکره‌ها آموزش دیده است:

  • Persian News Dataset — milad-4274/persian_news
  • Hamshahri Corpus — danialfarsi/hamshahri_corpus
  • JSON of Classic Persian Poems (گنجور) — namnamir/JSON_of_Classic_Persian_Poems
  • گفتگوهای آغازین: نوشته‌شده برای همین پروژه (۱۴۰ نمونه)

حقوق متن‌های اصلی متعلق به صاحبان آن‌هاست. این پروژه برای پژوهش و آموزش است و مالکیت داده‌های اصلی را ادعا نمی‌کند.

مجوز

کد این پروژه با مجوز MIT منتشر شده است: استفاده، تغییر و انتشار آزاد است، با ذکر منبع. وزن‌های مدل به‌صورت NPZ در مخزن قرار دارند و با همان مجوز منتشر می‌شوند.

حریم خصوصی

  • همهٔ داده‌ها روی همان سروری ذخیره می‌شوند که سایت را اجرا می‌کند؛ هیچ درخواستی به سرویس هوش مصنوعی بیرونی فرستاده نمی‌شود.
  • رمز عبور با scrypt و نمک یکتا ذخیره می‌شود؛ متن رمز هیچ‌جا نگه‌داری نمی‌شود.
  • نشست‌ها با کوکی HttpOnly و هش SHA-256 توکن مدیریت می‌شوند.
  • گفتگوی شما به‌صورت خودکار برای آموزش مدل استفاده نمی‌شود.
  • می‌توانی هر گفتگو یا همهٔ گفتگوها را حذف کنی؛ حذف واقعی است، نه پنهان‌سازی.

شرایط استفاده

  • رایان مدل کوچکی است و ممکن است پاسخ نادرست بدهد. برای تصمیم‌های مهم به آن تکیه نکن.
  • از سرویس برای تولید محتوای آسیب‌زا، آزار، یا نقض قوانین استفاده نکن.
  • سهمیهٔ روزانه برای حفظ دسترسی همه اعمال می‌شود؛ دور زدن آن با ساخت حساب انبوه مجاز نیست.
  • سرویس «همان‌گونه که هست» ارائه می‌شود، بدون تضمین دسترس‌پذیری دائمی.
