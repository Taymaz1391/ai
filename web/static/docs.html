مستندات رایان

هر چیزی که برای اجرا، استفاده و استقرار لازم داری. اگر می‌خواهی از صفر یاد بگیری، دورهٔ ۵ ساعتهٔ رایان مسیر کامل است.

شروع سریع

git clone https://github.com/Taymaz1391/ai.git
cd ai
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python web/server.py --host 0.0.0.0 --port 8000

سپس http://localhost:8000 را باز کن. مدل از checkpoints/rayan-1-small.npz بارگذاری می‌شود و روی CPU اجرا می‌شود.

برای گفتگو در ترمینال:

python scripts/chat_cli.py --deep

سهمیه و محدودیت

  • مهمان: ۲۵ پیام و ۱۰ اندیشهٔ ژرف در روز
  • حساب رایگان: ۲۰۰ پیام و ۸۰ اندیشهٔ ژرف
  • هر IP: حداکثر ۴۵ درخواست در دقیقه
  • طول متن هر پیام: ۲٬۰۰۰ نویسه؛ حداکثر ۲۲۰ توکن پاسخ

معماری

مسیر یک پیام:

  1. متن کاربر با rayan.text.normalize نرمال می‌شود.
  2. قالب گفتگو ساخته می‌شود: <|doc|> <|user|> … <|bot|> و دو نوبت آخر تاریخچه.
  3. مدل با حافظهٔ KV توکن‌به‌توکن تولید می‌کند؛ نمونه‌گیری با دما، top-p، top-k و جریمهٔ تکرار.
  4. پاسخ در SQLite ذخیره و به مرورگر جریان داده می‌شود.

زبان و ویدیوی تبلیغاتی

زبان پیش‌فرض فارسی است. اگر مرورگر زبان فارسی یا انگلیسی بفرستد، همان انتخاب می‌شود؛ وگرنه کشور بازدیدکننده از سرصفحهٔ پراکسی میزبان (مثل cf-ipcountry در Cloudflare) خوانده می‌شود و در آخر منطقهٔ زمانی مرورگر به‌عنوان سیگنال جایگزین به کار می‌رود. هیچ درخواستی به سرویس GeoIP بیرونی زده نمی‌شود؛ اگر جدول محلی data/geoip.json را بگذاری، همان ملاک است (قالب نمونه: data/geoip.sample.json؛ مسیر دیگر را با متغیر RAYAN_GEOIP بده). ویدیوی تبلیغاتی هم به همین زبان و به نسبت صفحه (افقی، عمودی یا مربعی) انتخاب می‌شود.
