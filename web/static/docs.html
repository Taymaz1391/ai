ورود شروع گفتگو
شروع سریع API سهمیه و محدودیت معماری استقرار پرسش‌ها

مستندات

هر چیزی که برای اجرا، استفاده و استقرار لازم داری. اگر می‌خواهی از صفر یاد بگیری، دورهٔ ۵ ساعتهٔ مسیر کامل است.

شروع سریع

git clone https://github.com/Taymaz1391/ai.git
cd ai
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python web/server.py --host 0.0.0.0 --port 8000

سپس http://localhost:8000 را باز کن. مدل از checkpoints/rayan-1-small.npz بارگذاری می‌شود و روی CPU اجرا می‌شود.

برای گفتگو در ترمینال:

python scripts/chat_cli.py --deep

سهمیه و محدودیت

  • مهمان: ۲۵ پیام و ۱۰ اندیشهٔ ژرف در روز
  • حساب رایگان: ۲۰۰ پیام و ۸۰ اندیشهٔ ژرف
  • هر IP: حداکثر ۴۵ درخواست در دقیقه
  • طول متن هر پیام: ۲٬۰۰۰ نویسه؛ حداکثر ۲۲۰ توکن پاسخ

معماری

مسیر یک پیام:

  1. متن کاربر با rayan.text.normalize نرمال می‌شود.
  2. قالب گفتگو ساخته می‌شود: <|doc|> <|user|> … <|bot|> و دو نوبت آخر تاریخچه.
  3. مدل با حافظهٔ KV توکن‌به‌توکن تولید می‌کند؛ نمونه‌گیری با دما، top-p، top-k و جریمهٔ تکرار.
  4. پاسخ در SQLite ذخیره و به مرورگر جریان داده می‌شود.

زبان و ویدیوی تبلیغاتی

سایت تک‌زبانه است: همهٔ صفحه‌ها lang="fa" و dir="rtl" هستند و هیچ کلید زبان، هدایت خودکار یا تشخیص GeoIP وجود ندارد. ویدیوی تبلیغاتی فقط بر اساس نسبت صفحه انتخاب می‌شود (افقی برای دسکتاپ، عمودی برای موبایل، مربعی برای شبکه‌های اجتماعی) و فارسی است.

کلاینت‌های نصب

/download نسخهٔ اندروید (APK) و ویندوز (EXE) را با نشانی ثابت به انتشار clients در GitHub پیوند می‌دهد. هر دو پوستهٔ نازک‌اند: مدل و سهمیه سمت سرور است و نشانی سرور را در نخستین اجرا می‌پرسی. ساختشان با .github/workflows/clients.yml انجام می‌شود.

بنچمارک شفاف

هیچ ادعای «جلو زدن از مدل‌های مرزی» در این پروژه نیست. نتیجهٔ سنجه‌های واقعی (ابزار محلی، خط فارسی، تولید متن، تأخیر و هزینه) در /api/benchmark و در فایل docs/BENCHMARKS.md منتشر می‌شود و با python scripts/benchmark.py بازتولید می‌شود. جدول مرجع Opus 5.5 هم آن‌جاست، ولی مقایسهٔ هم‌سنگ نیست: آن بنچمارک‌ها عامل‌محور و چندمرحله‌ای‌اند.

استقرار

سه مسیر رایگان:

  • Hugging Face Spaces (Docker): فایل Dockerfile با پورت ۸۰۰۰ آماده است.
  • Render: render.yaml و Procfile آماده‌اند.
  • GitHub Pages (فقط فرانت): با workflow موجود، نسخهٔ استاتیک روی دامنهٔ github.io منتشر می‌شود و با تنظیم apiBase به بک‌اند وصل می‌گردد.
